# Dublin-Bikes-Occupancy

Machine Learning analysis of Dublin bike station occupancy and demand forecasting.

## Project Overview
- Data: Dublin bike station records (CSV)
- Notebook: `DublinBikesOccupancy_Final.ipynb`
- Reports: `Stats_Report.pdf`
- Documentation: `Group_9_Dublin_Bike_Usage.docx`, presentation (`Group 9 ppt.pdf`)

## Setup
```bash
pip install pandas numpy scikit-learn matplotlib seaborn folium
```

## Usage
Open `DublinBikesOccupancy_Final.ipynb` to run the analysis.

## Data
- `dublin_bike_stations_full_data.csv`
